Network Expansion

When working through a network expansion, due to running out of IP address space in existing subnets and needing to update existing firewall rules to allow traffic to the new additional subnets, this XLSM spreadsheet contains VBA which takes an existing firewall rule export and using source/destination IP/CIDR block, and a mapping table, creates a new tab with the additional rules which would be required.

This is for a specific use case, but very transferable.
